How do I load it in the game?

Import the .mcpack and add its behavior pack to the world. A file at the pack root is named mystructure:name, so run /structure load mystructure:name ~ ~ ~ (a bare name also works in the structure block, which adds mystructure:). A file in a folder uses the folder as its namespace, like /structure load folder:name ~ ~ ~. Names allow only lowercase letters, digits, _ and -. A structure block saves at most 64 x 384 x 64. Bigger ones still load with the command.

Help

Structure Viewer opens a .mcstructure (a build saved with the Bedrock structure block or /structure save) in 3D with the real game textures. Nothing is uploaded.

Moving around

  • Drag rotates.
  • Right-drag or two fingers moves.
  • Wheel or pinch zooms.
  • Hover shows the block name.
  • Click pins a block and opens its card.
  • Reset view fits the whole build.

The tabs

  • File: what is loaded, its problems and export. Download pack gives a .mcpack with your structure: open it and Minecraft imports it. Pack + source (.zip) adds the raw pack folder next to it. Needs a loaded file, not the example.
  • View: Layers works like Litematica. The slider hides everything above a height, Single layer shows only that height. Water layer is the second block layer of the file. Structure void shows skipped cells as purple wireframes.
  • Light: shaders, shadows and time of day.
  • Materials: every block type. Click one to highlight it.

Problems

  • Could not read the file.
  • Offline: the build is drawn in flat colors.
  • A block without texture is drawn flat.

Good to know

  • Textures download once from Mojang's public bedrock-samples repo. New blocks fall back to its preview branch.
  • Shapes follow the block states: stairs, doors, fences, walls, panes, signs, rails...
  • Liquids are flat at their level. Beds are always drawn red.
  • Your toggles are saved in this browser.
